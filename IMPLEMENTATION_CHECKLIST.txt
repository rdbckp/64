================================================================================
TROUBLESHOOTING
================================================================================

BUILD ERROR: "BOARD_VNDK_VERSION not defined"
  → Make sure BoardConfig.mk has: BOARD_VNDK_VERSION := 30

BUILD ERROR: "Image.gz not found"
  → Kernel didn't build as arm64. Check:
    - KERNEL_TARGET_ARCH := arm64 in BoardConfig
    - a02_defconfig (check if it has ARM64 enabled)
    - Try: make kernel KERNEL_CROSS_COMPILE=aarch64-linux-android-

BOOT LOOP: No /vendor partition found
  → Check: fstab.mt6739 has correct partition paths
  → Check: vendor.img is flashed

BOOT LOOP: SELinux denials
  → Expected for first-boot. Use permissive:
    - Edit BoardConfig: BOARD_SELINUX_PROFILE := (leave as is for permissive)
    - Or `adb shell setenforce 0` if booted

ADB NOT WORKING: Device not visible
  → Device might be in boot loop. Reflash and monitor serial logs
  → Try: `fastboot reboot bootloader` + `adb connect` over TCP
